# Expense Tracker

A React Native expense tracking app built with React Native CLI.

## Features
- Add, view and delete transactions
- Monthly income, expense and balance summary
- Category-wise breakdown with charts
- Budget limits with overspend alerts
- Data persisted with AsyncStorage via Zustand

## Tech Stack
- React Native CLI
- Zustand (state management + persistence)
- React Navigation (stack + bottom tabs)
- react-native-chart-kit (charts)
- react-native-vector-icons
